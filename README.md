## About the Book

This repository organizes practical Python learning into a modular textbook, from first instructions and built-in types through control flow, collections, functions, reliable file work, data structures, and introductory data workflows. It is designed for learners who want to understand not only what to type, but why the code behaves as it does.

Examples are grounded primarily in the author's `.py` scripts, Jupyter notebooks, notes, and visual references. The later data-science chapters introduce a responsible path toward statistics, machine learning, and AI; topics not implemented in the source material are clearly presented as future study rather than completed lessons.

Third-party reference books are used only for topic discovery and coverage checks. Their prose, examples, and exercise wording are not reproduced.

## Course Features

- Beginner-to-advanced learning progression with intuitive analogies and motivating scenarios.
- Repository-based code examples with line-by-line explanations.
- Technical deep dives into execution, memory references, iteration, complexity, and data representation.
- ASCII diagrams, comparison tables, and links to selected course visuals and interactive graph/trie references.
- Common errors, boundary cases, testing ideas, and exercises with hints.
- Practical projects spanning command-line programs, registries, data structures, and data reports.
- Clear separation between existing repository coverage and proposed future learning paths.

## Quick Start

### Read the textbook

1. Open [`Chapter 1`](PYTHON_TEXTBOOK/Chapter_01_Python_Basics/01_Introduction_and_Setup.md).
2. Follow the chapter folders in order using the chapter map above.
3. Work through the code examples and exercises. When a topic links to a source notebook or script, compare the explanation with the original.

No Python installation is needed to read the Markdown textbook.

### Run the source examples

1. Clone the repository:

   ```bash
   git clone https://github.com/Farhanillahiclass/Python-Core-and-Advanced-Handbook.git
   cd Python-Core-and-Advanced-Handbook
   ```

2. Open the folder in VS Code or another Python editor.
3. Select a Python interpreter and, for notebooks, a matching Jupyter kernel.
4. Run a `.py` script with the selected interpreter or execute notebook cells in order.

Some data-library notebooks use pandas, NumPy, Matplotlib, Seaborn, and an Excel writer. Install only the dependencies needed for the notebook you are running, in the environment selected for that project. The repository's local `.venv` and `.conda` directories are intentionally excluded from version control.
